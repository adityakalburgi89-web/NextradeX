# Security Policy for NexTradeX

## Educational & Simulation Disclaimer
NexTradeX is a **mock paper trading platform** designed solely for educational, research, and simulation purposes.
- No real monetary assets, cryptocurrency funds, or live brokerage balances are processed or held.
- All trading features operate in a simulated sandboxed environment.

## Reporting a Security Vulnerability
If you discover a security vulnerability in the platform (e.g. rate limiting bypasses, authentication flaws, OAuth token mishandling), please report it responsibly:

1. **Email**: Open a security issue on the repository or contact the core maintainer.
2. **Details**: Provide a detailed description of the flaw, reproduction steps, and potential impact.
3. **Response Time**: We aim to acknowledge vulnerability reports within **48 hours**.

Thank you for helping keep NexTradeX secure!
